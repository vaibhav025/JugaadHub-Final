# JugaadHub

JugaadHub is a student-focused platform that allows college students to rent and lend appliances and personal items within their campus community — safely and conveniently.

---

## Overview

College students often need short-term access to items like calculators, speakers, books, or appliances. Buying them isn’t always practical.

**JugaadHub solves this by:**
- Enabling peer-to-peer rentals within college
- Building trust using verified student identities
- Protecting both renter and lender through security features

---

## Key Features

### Student Verification
- College email verification ensures only genuine students can access the platform

### Secure Transactions
- Security deposit system to protect lenders
- Safe and controlled renting process

### Product Protection
- Mandatory **before & after image uploads**
- Helps avoid disputes over product damage

### Authentication System
- Login & Registration
- OTP Verification for added security
- JWT-based authentication for secure sessions

## How It Works (Simple Flow)

1. User signs up using college email  
2. OTP verification completes authentication  
3. User lists an item with images  
4. Another student rents it by paying deposit  
5. Before & after images ensure product safety  
6. Deposit is returned after verification
